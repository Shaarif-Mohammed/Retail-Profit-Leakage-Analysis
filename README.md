# Retail Profit Leakage & Discount Effectiveness Analysis

## Project Overview

This project investigates how discounts, product mix, and regional performance affect retail profitability.

## Business Problem

A retail company is experiencing strong sales growth, but profits are not increasing proportionally. This project aims to identify sources of profit leakage and evaluate discount effectiveness.

## Objectives

- Identify loss-making products
- Analyze discount effectiveness
- Evaluate regional profitability
- Design a star schema data model
- Build a Power BI dashboard

## Tools

- PostgreSQL
- SQL
- Power BI
